Política de privacidad — Jaque Global MX Uploader

Última actualización: 24 de noviembre de 2026

1. Qué hace la aplicación

Jaque Global MX Uploader es una herramienta interna que el equipo del canal de YouTube Jaque Global MX ejecuta en su propia computadora para subir los videos del canal mediante la API de datos de YouTube (YouTube API Services).

2. Datos a los que accede

Con la autorización del propietario del canal, la aplicación solicita los permisos de YouTube necesarios para subir y administrar videos del canal (youtube.upload y youtube). Solo accede al canal que la autorizó. No accede a datos de otros usuarios, espectadores ni cuentas de terceros.

3. Cómo se usan y se guardan

  • Los datos se usan únicamente para subir videos, miniaturas, títulos, descripciones, etiquetas y listas de reproducción del propio canal.
  • El token de acceso se guarda solo en la computadora del propietario del canal, en un archivo local. No se envía a ningún servidor propio ni a terceros.
  • No vendemos, compartimos ni transferimos datos de usuario. No se usan para publicidad.

4. Servicios de Google

La aplicación usa YouTube API Services. Al usarla aceptas también los Términos de servicio de YouTube y la Política de privacidad de Google. El uso y la transferencia de la información recibida de las API de Google cumple con la Google API Services User Data Policy, incluidos los requisitos de uso limitado.

5. Revocar el acceso y borrar datos

El acceso puede revocarse en cualquier momento desde la configuración de seguridad de tu cuenta de Google. Al revocarlo, el token local deja de funcionar y se elimina del archivo local.

6. Contacto

Para preguntas sobre esta política, usa la información de contacto de la página "Acerca de" del canal: youtube.com/@JaqueGlobalMX.

English summary

Jaque Global MX Uploader is an internal tool used by the Jaque Global MX YouTube channel to upload its own videos through YouTube API Services. With the channel owner's consent it requests YouTube upload/manage scopes for that channel only. The access token is stored only on the owner's computer; no user data is sold, shared or transferred, and it is not used for advertising. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements. See the YouTube Terms of Service and the Google Privacy Policy. Revoke access any time at myaccount.google.com/permissions.
