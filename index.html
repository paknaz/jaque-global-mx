Jaque Global MX

El tablero del mundo, explicado para México.

Qué es

Jaque Global MX es un canal de YouTube de análisis geopolítico en español: Estados Unidos, Irán, China, Rusia, Israel, América Latina y lo que cada movimiento significa para México. Cada video cita sus fuentes y separa lo verificado de lo que todavía no se confirma.

Ver el canal en YouTube

Jaque Global MX Uploader

"Jaque Global MX Uploader" es una herramienta interna del canal. Usa la API de datos de YouTube únicamente para subir los videos del propio canal Jaque Global MX, con su título, descripción, etiquetas, miniatura y lista de reproducción. No está dirigida al público y no accede a cuentas de otras personas.

"Jaque Global MX Uploader" is the channel's internal tool. It uses the YouTube Data API only to upload the channel's own videos (title, description, tags, thumbnail, playlist) to the Jaque Global MX channel.
